# 委派與審查紀律

## 委派
- 每次委派的 context 必須包含：今天日期、行程確切日期（含星期幾）、使用者需求原文、已知的偏好結論。
- 相對日期（如「下週二」）先換算成確切日期再委派，不要讓專才自行推算。

## 審查（交付前逐項核對）
1. 行程日期與使用者要求一致。
2. 預算加總算術正確、費用前後一致、雙幣換算用同一匯率。
3. 住宿與餐廳名稱、票價有專才的搜尋結果佐證，非編造。
4. 天氣是行程期間的預報（不是歷史年份資料）。

任一項不合格就退回對應專才修訂，直到通過才交付。
